# 방화벽 규칙 목록

> 지시서 산출물 ②. 아래 "적용 기록"은 `10`/`11`/`13-firewall-*.ps1`이 실행될 때마다 **실제 실행한 명령과 적용 결과를 자동으로 덧붙인다.**
> 스크립트 폴더를 USB에서 바로 실행하면 모든 PC의 기록이 이 파일 하나에 모인다.

## 원칙

- 규칙 이름은 모두 `Finesse-` 접두사. 한 번에 조회: `Get-NetFirewallRule -DisplayName "Finesse-*" | Get-NetFirewallAddressFilter`
- 한 번에 삭제 (되돌리기): `Get-NetFirewallRule -DisplayName "Finesse-*" | Remove-NetFirewallRule`
- `RemoteAddress`는 항상 팀 PC IP로 제한한다. `Any` / 방화벽 끄기는 금지 (**llama-server는 인증이 없다**).
- 네트워크 프로필(공용/개인)은 바꾸지 않는다. 규칙에 `-Profile Domain,Private,Public`을 명시한다.
- 같은 이름의 규칙이 있으면 삭제 후 재생성하므로 스크립트를 여러 번 실행해도 규칙이 중복되지 않는다.

## 적용 예정 규칙 (config/pcs.json 기준, 2026-09-28)

| 규칙 | 적용 PC | 포트 | 허용 원격 IP | 상태 |
|---|---|---|---|---|
| `Finesse-LLM-8081-In` | 301B-11, 301B-13 | TCP 8081 | 백엔드 PC IP (+ `extraLlmAllow`) | ⏸ **백엔드 PC 미정** — 정해지기 전에는 스크립트가 적용을 거부한다 |
| `Finesse-LLM-App-In` (선택) | 301B-11, 301B-13 | TCP 8081 + `llama-server.exe` | 위와 같음 | `-ServerExe` 를 줄 때만 생성. 첫 실행 때 "Windows 보안 경고" 창을 막는다 |
| `Finesse-Backend-8080-In` | 백엔드 PC (미정) | TCP 8080 | 팀 PC 12대 (`backendAllow`, 자기 자신 제외) | ⏸ 백엔드 PC 미정 |
| `Finesse-Frontend-5173-In` (선택) | 프론트 PC (미정) | TCP 5173 | 팀 PC 12대 (`backendAllow`) | ⏸ 필요할 때만 |
